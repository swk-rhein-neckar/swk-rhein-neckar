# Vision
In der Rhein-Neckar-Region gibt es eine lebendige Community, in der sich Menschen aus der Softwareentwicklung regelmäßig austauschen, voneinander lernen und gemeinsam besser werden.

# Mission
Wir bringen Menschen aus der Softwareentwicklung zusammen und schaffen Gelegenheiten für offenen Austausch, gemeinsames Lernen und die Weitergabe praktischer Erfahrungen.
